## テーマをどう活かしたか
**Boundary** → **「境界線」** と捉えて、境界線を使うことでプレイヤーをゴールへ導くゲームを考えました

## 概要
### ゲームの特徴
- プレイヤーは自由に境界線を引けます。
線を境に世界が分かれ、片側は重力あり、もう片側は無重力になります。
境界線をうまく配置して、ゴールを目指すゲームです！


## 操作方法

| キー | 操作 |
|------|------|
| A | 左移動 |
| D | 右移動 |
| R | リスタート |
